Directory Structure

Below is the recommended structure of the extension project:

extension/
├─ manifest.json           # Main configuration for Chrome Extension
├─ content file            # this is the file that as all the injected codes while the pdf loads 
├─ background.js           # Background script for persistenttasks
├─ popup.html              # Popup interface            
├─ popup.css               # Optional settings page
├─ ALL THE WORDS.JS        # list of all the worlds in object structure
├─ display.js              # this is service worker js file
├─ options.js              # Logic for options page
├─ icons/                  # Folder containing extension icons
└─ README.md               # Project documentation

Setup Instructions

  1. Clone the repository: git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
  2. Open Chrome and go to chrome://extensions/
  3. Enable Developer Mode (top right corner)
  4. Click Load unpacked and select the project folder
  5. The extension should now appear in Chrome toolbar

Key Files and Their Purpose

  • manifest.json – Defines extension metadata, permissions, scripts, and UI elements.
  • background.js – Handles background tasks and persistent operations.
  • content.js – Runs in web pages, modifies DOM, and handles page interactions.
  • popup.html / popup.js – The user interface when the extension icon is clicked.
  • display.js – inject the js in every active tab.
  • icons/ – Stores all icon assets for different resolutions.

Development Guidelines

  • Follow consistent code formatting and comments for readability.
  • Test changes thoroughly in Chrome before committing.
  • Use semantic variable and function names.
  • Ensure backward compatibility whenever possible.
  • Update version number in manifest.json for each release.
